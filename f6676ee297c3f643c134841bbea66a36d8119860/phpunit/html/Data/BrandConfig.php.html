7/**
8 * Brand configuration accessor.
9 *
10 * Provides brand-specific values (slug, theme, basename, display name)
11 * derived from the module loader container so the reset module works
12 * for any Newfold brand without hardcoded references.
13 */
14class BrandConfig {
15
16    /**
17     * Get the default theme slug for the factory reset.
18     *
19     * Returns WordPress core's own default theme for the running version, via
20     * the core `WP_DEFAULT_THEME` constant (e.g. `twentytwentyfive` on WP 6.7+,
21     * `twentytwentyfour` on 6.4–6.6, and so on). That is the theme core itself
22     * activates on a fresh install and falls back to when the active theme is
23     * broken, so restoring it is the most literal "return to stock WordPress."
24     *
25     * Using the core constant rather than a fixed slug is deliberate:
26     *
27     * - A factory reset must wipe the slate clean and work on any site, old or
28     *   new. `WP_DEFAULT_THEME` is version-matched to the site, so it is always
29     *   bundled with that core and always compatible — the reset never installs
30     *   a theme that requires a newer WordPress than the site runs. (A fixed
31     *   `twentytwentyfive` would require WP 6.7+ and break resets on older
32     *   sites.) On the common path it resolves locally with no WordPress.org
33     *   fetch at all.
34     * - Applying a brand theme is onboarding's job, not the reset's. Onboarding
35     *   re-runs after a reset and installs whatever theme the brand wants.
36     * - Being brand-agnostic removes a whole class of bug: a per-brand theme
37     *   slug that is a placeholder, gets deprecated, or is delisted from
38     *   WordPress.org would silently break the reset (see PRESS0-5302, where
39     *   HostGator pointed at a non-existent "flavor" theme).
40     *
41     * `WP_DEFAULT_THEME` has shipped with core since WordPress 3.0 and is
42     * always defined by the time this runs (set during the WordPress bootstrap,
43     * before any plugin, REST, or admin-page code), so no fallback is needed.
44     *
45     * @return string
46     */
47    public static function get_default_theme_slug() {
48        return WP_DEFAULT_THEME;
